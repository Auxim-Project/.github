# Auxim

**Open-source infrastructure for modular AI agents.**

Auxim is an open-source project exploring a modular environment for building, running, and extending AI agents.

The project aims to separate agent applications from the infrastructure they run on, creating a foundation for extensibility and human–AI collaboration.

## Projects

| Repository | Description |
| --- | --- |
| [Auxim Agent](https://github.com/Auxim-Project/auxim-agent) | The default agent implementation for the Auxim platform. |
| [Auxim Kernel](https://github.com/Auxim-Project/auxim-kernel) | Execution and resource-control foundation for the Auxim agent environment. |
| [Auxim WebINF](https://github.com/Auxim-Project/auxim-webinf) | Gateway and web-facing infrastructure for the Auxim platform. |

## Project Status

Auxim is under active development.

Its architecture and APIs are evolving as the core components are developed and refined. Documentation, features, and interfaces may change.
